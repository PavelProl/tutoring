# Библиотека устроена по собственным Темам, а не по кодификатору

Библиотека делится на Темы из собственного списка автора, общего для ОГЭ и ЕГЭ; каждая Тема ссылается на элементы кодификаторов ФИПИ конкретных экзаменов и лет, а Задание — на Тему и Номер КИМ. Так ежегодная смена кодификатора меняет только связи, а не саму библиотеку, и одна Тема (например, «Строение атома») служит и ОГЭ, и ЕГЭ.

## Considered Options

- **Элемент кодификатора как Тема.** Кодификаторы ОГЭ и ЕГЭ разные и меняются по годам — библиотеку пришлось бы перестраивать.
- **Номер КИМ как Тема.** Удобно для натаскивания, но один номер КИМ охватывает несколько тем, а теорию по номерам не разделить.
