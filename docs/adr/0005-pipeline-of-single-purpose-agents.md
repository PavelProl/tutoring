# Конвейер из узких агентов; «Проверено» ставит только автор

Заменено: ADR 0008.

Содержание проходит шесть этапов, у каждого свой агент с узкой инструкцией: Оцифровка → сверка оцифровки → классификация (Тема, Подходит для, Номер КИМ, Сложность, дубли) → Решения → Конспект → сборка Комплекта (подбор — агент, вёрстка — скрипт без ИИ). Сверку делает не тот агент, что оцифровывал: проверяющий с тем же контекстом повторяет ошибки автора. Агенты ставят только Пометки; статус «Проверено» ставит автор, и в Комплект попадает только проверенное.

## Consequences

- Каждый этап можно оценивать отдельно (evals по этапам).
- Узкое место — проверка автором; сборщик называет, какие Задания нужно проверить для Комплекта, а не требует проверять всё подряд.
