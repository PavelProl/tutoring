# План работы и вход в проект

Приоритет — следующий проверенный Комплект школьной химии 8–9 классов после Темы 4. Подготовка не привязана к сдаче экзамена. Организационная сверка завершена в [#32](https://github.com/PavelProl/tutoring/issues/32); повторять её перед каждой Темой не требуется.

Здесь хранится согласованная **очерёдность**, а актуальные состояния, подробные чек-листы, проверки и передача — в соответствующих GitHub Issues. При изменении приоритетов обновляются эта страница и ссылки в #12; ход работы сюда не копируется.

## Как продолжает новый чат

1. Прочитать AGENTS обоих репозиториев, эту страницу и [workflow.md](workflow.md). Проверить активные issues/PR, затем последний комментарий выбранного issue. Не восстанавливать историю по старым комментариям вместо текущего описания.
2. Для содержания прочитать [карту курса](../../tutoring-content/course-map.md), [реестр](../../tutoring-content/source-inventory.md), [reading-sources.md](reading-sources.md) и [lesson-output.md](lesson-output.md). Выбирать только файлы нужного этапа, а не перечитывать весь проект.
3. Если поручение охватывает несколько этапов до Комплекта, завершать и передавать каждый последовательно. На недостающих материалах/решении автора фиксировать препятствие и конкретный запрос; независимую разрешённую работу продолжать. Метка afk и эта таблица не создают фонового запуска.
4. Исходники, коммиты и PR сохраняются по workflow; автор принимает итоговые PDF. Следующий чат получает состояние из файлов и issue, а не из памяти предыдущего агента.

Достаточное стартовое поручение: «Продолжай tutoring по docs/plan.md и последней передаче активного issue до готового Комплекта; запрашивай только недостающие материалы и решения». Это поручение не отменяет согласования дорогих пакетов и авторской приёмки.
