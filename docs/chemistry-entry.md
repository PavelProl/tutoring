# Рабочая папка chemistry

Эта инструкция хранится в Git репозитория tutoring. Локальный chemistry/AGENTS.md — ссылка на этот файл, чтобы чат из общей папки получил точку входа без отдельного репозитория правил.

- Из корня chemistry прочитай tutoring/AGENTS.md и tutoring-content/AGENTS.md, затем tutoring/docs/plan.md. План работ, включая очередность и отложенные идеи, ведётся в docs/plan.md. Перед запуском этапа проверь открытые in-progress и последнее состояние связанного GitHub issue.
- Один проект состоит из публичного tutoring, приватного tutoring-content и оригиналов tutoring-sources вне Git. Правила git/проверок — tutoring/docs/workflow.md. Основные копии остаются на main, изменения — в паре worktree.
- Для подготовки содержания используй tutoring-content/course-map.md и source-inventory.md, tutoring/docs/reading-sources.md и lesson-output.md. Не начинай Конспект до полной базы; запрашивай недостающие страницы до дорогой обработки. Доступ к оригиналам — только по текущему этапу, без автоматического чтения всех книг.
- Учёт учеников сейчас не используется; tutoring-students не требуется. Существующие учебные файлы и PDF автоматически не переделываются.
- После завершения этапа запиши проверки, доставку и остаток работы в связанном issue. Автоматического фонового диспетчера нет; переходы выполняются только в пределах явного поручения.
