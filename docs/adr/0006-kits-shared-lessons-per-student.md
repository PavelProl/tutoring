# Комплект общий для всех учеников; ученик — только в Занятии

Комплект не привязан к ученику: один Комплект по Теме и Экзамену служит всем, кто её проходит, и хранится в репозитории содержания. Всё, что касается конкретного ученика, — Занятие (ученик, дата, ID Комплекта, позже итоги) — хранится локально вне git вместе с остальными данными учеников. Так 20 учеников по одной Теме — это один Комплект и 20 коротких записей, а в репозитории содержания нет персональных данных, даже псевдонимов.

## Considered Options

- **Комплект на каждого ученика.** Позволяет подстраивать материалы, но при многих учениках — десятки почти одинаковых Комплектов; дополнительную практику вместо этого даёт Тренировка.
- **Комплекты в репозитории содержания с псевдонимом ученика.** Удобно копировать, но смешивает общий материал с учётом учеников.
