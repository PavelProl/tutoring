# План работы и вход в проект

Приоритет — последовательная подготовка школьных Тем 8–9 классов без привязки к сдаче экзамена. Здесь хранится согласованный план проекта: приоритеты, очередность и отложенные идеи. При изменении очередности обновляй этот файл. В связанных Issues хранятся объём конкретной работы, текущий статус, препятствия и подтверждение результата.

## Ближайшие шаги

| Порядок | Работа | Результат и условие перехода |
| --- | --- | --- |
| 1 | Обсудить вопросы автора по Теме 5 и коротко разобрать подготовку [принятого Комплекта](https://github.com/PavelProl/tutoring/issues/29) | Разобрать повторные сборки, приёмку и расход токенов. Зафиксировать нужные изменения в соответствующих правилах |
| 2 | Закрыть остаток по источникам и банку Заданий Темы 5 ([#23](https://github.com/PavelProl/tutoring/issues/23)) | Использовать полученные оглавления и разборы. Согласовать конкретные недостающие страницы, ключи, Решения и стоимость обработки. Сверить полноту базы и зафиксировать результат в реестре и issue |
| 3 | Выбрать следующую школьную Тему и определить её базу | Начать по отдельному поручению после закрытия вопросов автора и остатка по Теме 5. Выбор Темы утверждает автор |
| По потребности | Валидатор файлов Заданий ([#4](https://github.com/PavelProl/tutoring/issues/4)) | Перед большим пополнением банка. До реализации сохраняются явные ручные проверки |

Комплект Темы 5 принят по доступным материалам ([#29](https://github.com/PavelProl/tutoring/issues/29)). Полноту источников и банка проверяем отдельно в #23. Если по итогам понадобится менять принятый Комплект, объём правок согласуем с автором. Общая организационная сверка завершена в [#32](https://github.com/PavelProl/tutoring/issues/32).

## Как продолжить

1. Прочитать AGENTS обоих репозиториев, этот план и [workflow.md](workflow.md). Для обзора повестки достаточно плана. Перед запуском этапа сверить открытые `in-progress`, описание и последнюю передачу связанного issue, при необходимости — PR.
2. Для подготовки содержания использовать [карту курса](../../tutoring-content/course-map.md), [реестр источников](../../tutoring-content/source-inventory.md), [правила чтения](reading-sources.md) и [требования к выдаче](lesson-output.md). Открывать материалы нужного этапа.
3. Выполнять только этапы из поручения. При нехватке материалов или решения автора назвать конкретное препятствие и запрос. По завершении записать в связанном issue результат, проверки и остаток. Следующий этап берётся по поручению автора.
