# tutoring

Платформа репетитора по химии (ОГЭ/ЕГЭ): библиотека теории и заданий по темам и сборка из неё материалов к занятиям. Объясняй решения с доводами.

- Работай с оцифрованным содержанием. Источники (фото сборников, PDF-книги) лежат вне репозитория, в `../tutoring-sources/`; открывай их только при оцифровке. Исключение — образцы оформления в `../tutoring-sources/references/`: их открывай, когда работаешь над оформлением.
- В этом проекте «задача» и «задание» — всегда про химию (в документах и коде — «Задание»); работа по разработке — «issue» в GitHub Issues. Словарь — в `GLOSSARY.md`.
- Язык. По-русски — документация (README, GLOSSARY, ADR, AGENTS, скиллы) и содержание. По-английски — код и комментарии в нём, имена файлов и переменных, коммиты, ветки, метки, issues и PR. Термины словаря в английских текстах пишутся по их английским именам из `GLOSSARY.md` (`exercise`, `topic`, `lesson_kit`).
- Цели проекта — в `README.md`, принятые решения — в `docs/adr/`.
- Работа по разработке ведётся в GitHub Issues: `PavelProl/tutoring`. Issue, где нужны решения или проверка автора, помечен `hitl`; issue, который агент может сделать сам, — `afk`.
- Коммиты — по-английски, в формате Conventional Commits (`docs: …`, `feat: …`), без строки `Co-Authored-By`. Агент предлагает коммит и показывает, какие файлы в него входят; коммитит и пушит после подтверждения автора.
- Разбираешь источник или оцифровываешь Задания — сначала прочитай `docs/reading-sources.md`.
- Один чат — одна работа. Перед сменой чата запиши в память, где остановились, и проверь, что оглавление памяти (`MEMORY.md`) ведёт к этой записи; когда чат разрастается, предложи новый.
- Когда закрывается веха (Тема, разбор книги, инструмент), предложи запись в `docs/journal.md`.
