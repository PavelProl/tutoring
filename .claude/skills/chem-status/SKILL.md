# Сводка по химии

Собери данные и ответь в 5–10 строк, не больше:

1. **Конспекты:** по `../tutoring-content/course-map.md` — сколько Тем с готовым Конспектом, какая Тема следующая.
2. **Чтение:** по таблице чтения в карте — что прочитано и что дальше.
3. **Фото:** по таблице заявок — что заявлено и ещё не пришло.
4. **Незакоммиченное:** `git status --short` в `tutoring` и `../tutoring-content`.
5. **Issues:** `gh issue list --repo PavelProl/tutoring --state open`.
6. **Ученики:** «учёт не настроен» — пока его не устроит grilling «Ученики и планирование».

Если автор просит подробнее про одну строку («давай подробнее про …»), раскрой только её.
