# tutoring

Платформа репетитора по химии (ОГЭ/ЕГЭ): многоразовая библиотека теории и заданий по темам и сборка из неё материалов к занятиям — теории на слайдах, ДЗ, входной проверки и решений.

## Цели

По убыванию приоритета:

1. **Польза на занятиях** — готовиться к занятиям быстро и системно.
2. **Открытый инструмент** — в перспективе им смогут пользоваться другие преподаватели: сначала как кодом, который запускают у себя со своим содержанием, а затем, возможно, как веб-сервисом.

При конфликте целей сначала делаем то, что нужно к ближайшему занятию; технологию берём, только когда она решает настоящую проблему подготовки. Мерило успеха — проверенный автором Комплект к занятию.

## Куда идём

Целевая картина: автор пишет «новый ученик, 9 класс, занятие во вторник в 14:00» — система предлагает план и готовит Комплект; после занятия автор пишет короткий отчёт — система решает, что повторить и какую Тему дать дальше, напоминает о занятиях и материалах. Автор только подтверждает.

Шаги, по порядку:

1. Машина содержания: разбор источников → Конспект → Задания → Комплект.
2. Карта курса: все Темы, порядок, зависимости, заявки на фото Заданий.
3. Ученики: карточка, отчёт после занятия, прогресс по Темам.
4. Планировщик: «новый ученик» → план, «отчёт» → следующий Комплект.
5. Напоминания и расписание.
6. Больше автономии агентов — по мере доверия.

## Сборка PDF

Нужны Python 3.9+, Google Chrome (печатает HTML в PDF) и интернет (формулы KaTeX и шрифт грузятся из сети). Путь к Chrome в `tools/build_kit.py` записан под macOS.

```sh
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python tools/build_kit.py ../tutoring-content kits/oge/basic-concepts-1/kit.md
.venv/bin/python tools/build_kit.py ../tutoring-content tests/level-test-9.md
```

В `tutoring-content/build/` попадают только PDF. Комплект — в `build/oge/<NN>-<id Темы>-<N>/`: «Тема 2.1 — занятие.pdf», «— решения.pdf», «— преподавателю.pdf» и, если у Комплекта есть `entry_check`, «— входная проверка.pdf» (слайды 16:9 по ДЗ этого Комплекта, проводятся в начале следующего занятия). Тест — в `build/tests/<название>.pdf`. В `theory_block` можно выбрать Разделы: `notes/basic-concepts.md#4,6-8`; Разделы с пометкой `<!-- exams: ЕГЭ -->` в Комплект ОГЭ не попадают.
