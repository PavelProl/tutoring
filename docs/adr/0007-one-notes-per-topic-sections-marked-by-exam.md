# Один Конспект на Тему; Разделы для ЕГЭ помечены

Конспект один на Тему и общий для ОГЭ и ЕГЭ. Раздел без пометки годится для обоих Экзаменов; Раздел, нужный только для ЕГЭ, помечен `<!-- exams: ЕГЭ -->`. Комплект ОГЭ берёт только Разделы без пометки, Комплект ЕГЭ — все. Помечается Раздел целиком, а не абзац: так сборке достаточно фильтра по Разделам, а автору — проверить заголовок. Задания уже размечены полем `suitable_for`, Комплекты и так свои для каждого Экзамена; пометка Раздела закрывает последний общий материал.

Повод: одновременно занимаются ученик 9 класса (ОГЭ) и ученик 11 класса (ЕГЭ) по одной Теме.

## Considered Options

- **Два Конспекта на Тему (ОГЭ и ЕГЭ).** Общие 70–80 % текста жили бы в двух копиях: исправление одной терялось бы в другой, проверять пришлось бы дважды.
- **Пометки внутри Раздела (по абзацам).** Точнее, но Раздел перестаёт читаться целиком, а сборка и проверка усложняются.
