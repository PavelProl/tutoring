# tutoring

Платформа репетитора по химии (ОГЭ/ЕГЭ): библиотека теории и заданий по темам и сборка из неё материалов к занятиям. Автор — преподаватель и начинающий разработчик: объясняй решения так, чтобы он мог защитить каждое сам.

- Работай с оцифрованным содержанием. Источники (фото сборников, PDF-книги) лежат вне репозитория, в `../tutoring-sources/`; открывай их только при оцифровке. Исключение — образцы оформления в `../tutoring-sources/references/`: их открывай, когда работаешь над оформлением.
- В этом проекте «задача» и «задание» — всегда про химию (в документах и коде — «Задание»); работа по разработке — «issue» в GitHub Issues. Словарь — в `GLOSSARY.md`.
- Документация и содержание — по-русски; код, имена файлов и переменных — по-английски.
- Цели проекта — в `README.md`, принятые решения — в `docs/adr/`.
