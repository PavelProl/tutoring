# Как читать источники

Правила для агентов, которые разбирают книги и сборники (`tutoring-content/analysis/`) и оцифровывают Задания. Приняты 27.10.2026 (см. `docs/journal.md`).

## Правда — изображение страницы

Текстовый слой PDF точен в словах и цифрах, но теряет вёрстку: стрелки реакций (обратимая `⇄` превращается в пробелы), верхние и нижние индексы, заряды ионов, схемы и таблицы. Поэтому:

- обычный текст (определения, рассуждения, условия без формул) читай по текстовому слою (`pdftotext -layout`);
- если на странице есть формула, уравнение реакции, схема или таблица, открой изображение страницы и выпиши эти места с него. Признаки в тексте: пустоты между формулами, цифры после символов элементов, слова «схема», «рисунок», «таблица»;
- фото и сканы без текстового слоя читай изображениями целиком.

## Фото: читать, только когда отданы все

Автор снимает источники постепенно, поэтому папка с фото может быть неполной. У каждой заявки в `course-map.md` статус: «заявлено» → «снимаю» → «все фото отданы». Последний ставит только автор. Пока его нет, агент такой источник не читает и спрашивает: «Все ли фото по … ты отдал?»

## Разбор — полный, Конспект — под Тему

- Разбор источника делается один раз, по всем страницам, подробно: это основа для всех Тем. Экономить на полноте нельзя, выборочное чтение не годится. Если источник велик для одного прохода, раздели его между агентами; в итоге напиши, что прочитано и что нет.
- «Начала химии» (`chemistry_base.pdf`) — главный источник реакций и Заданий для Конспектов и Тренировки; школьные учебники — для школьной подачи и определений.
- Сборка Конспекта читает не книги, а разделы разборов, относящиеся к Теме, и изображения нужных страниц для точной выписки.

## Агенты

- Один агент — одна глава (примерно 20–40 страниц).
- Агент дописывает итог в файл разбора после каждого раздела. После паузы или сбоя новый агент читает файл и продолжает с места остановки.
- Параллельно — не больше 2–3 агентов, чтобы лимит оставался на подготовку к занятиям.
- Модель: Sonnet. Эксперимент 27.10.2026 («Начала», гл. 12): по задачам Sonnet не уступил Opus, нашёл те же опечатки, автор сверил страницу — ошибок нет.
- Проверка модели — по каждой главе. Агент пересчитывает расчётные ответы книги. Автору агент показывает одну страницу с уравнениями: картинку и выписку рядом. Если найдена ошибка, глава перечитывается на Opus. Каждая пятая глава читается обеими моделями, их разборы сравниваются.
