# tutoring

Платформа репетитора по химии (ОГЭ/ЕГЭ): многоразовая библиотека теории и заданий по темам и сборка из неё материалов к занятиям.

## Библиотека

**Тема** (`topic`):
Раздел химии из собственного списка тем автора, общий для ОГЭ и ЕГЭ. Связана с элементами кодификаторов разных экзаменов и лет; библиотека устроена по Темам.
_Avoid_: раздел, параграф

**Элемент кодификатора** (`codifier_element`):
Пункт кодификатора ФИПИ конкретного экзамена и года (например, ЕГЭ-2027, 1.1). Тема ссылается на один или несколько таких пунктов.
_Avoid_: код темы

**Номер КИМ** (`kim_number`):
Номер задания в экзаменационной работе конкретного экзамена (например, ЕГЭ №1).
_Avoid_: линия

**Конспект** (`notes`):
Авторский текст теории по одной Теме. Один на Тему; Источники служат для него только входом.
_Avoid_: теория по теме, справка

**Раздел** (`section`):
Часть Конспекта с одной мыслью: заголовок, Суть, Подробно и иллюстрации. Раздел, нужный только для ЕГЭ, помечен; без пометки — для обоих Экзаменов (ADR 0007).
_Avoid_: параграф, пункт

**Суть** (`gist`):
Короткая часть Раздела для слайда: тезис в 1–3 строки и подкрепляющие его уравнения реакций или примеры.

**Подробно** (`details`):
Связный текст Раздела для чтения.

**Что нужно знать** (`must_know`):
Перечень знаний и умений, нужных для решения Заданий Темы. Выводится из Заданий и задаёт, что должен покрыть Конспект.

**Задание** (`exercise`):
Единица для ученика: условие с Ответом и, возможно, Решением. Одно и то же условие с тем же Ответом из разных Источников — одно Задание; с другими числами — другое. В речи «задача» означает то же самое; в документах и коде пишется «Задание».
_Avoid_: упражнение, вопрос, `task`

**Основная Тема** (`main_topic`):
Единственная Тема, к которой Задание относится в первую очередь. Кроме неё у Задания могут быть дополнительные Темы.

**Экзамен** (`exam`):
ОГЭ или ЕГЭ.

**Подходит для** (`suitable_for`):
Экзамены, в кодификаторе которых есть знание, проверяемое Заданием. Определяется по содержанию, независимо от того, из какого Источника Задание и совпадает ли его формат с Номером КИМ.

**Сложность** (`difficulty`):
Уровень Задания по шкале КИМ ФИПИ: базовый, повышенный, высокий.

**Расчётная задача** (`calculation`):
Задание, Ответ которого вычисляется по данным условия.

**Ответ** (`answer`):
Правильный результат Задания, обычно из ключа сборника. Есть у каждого Задания.

**Решение** (`solution`):
Ход рассуждения от условия к Ответу. Необязательно: пишется, когда Задание впервые нужно в Комплекте, и дальше переиспользуется.
_Avoid_: разбор, пояснение

**Тренировка** (`practice_set`):
Проверенные Задания одной Темы, которых ученик ещё не встречал, по возрастанию Сложности, с Ответами в конце, без Решений. Для самостоятельной дополнительной практики.
_Avoid_: дополнительные задания, тренажёр

**Справочный лист** (`reference_sheet`):
Авторская сводная таблица или схема по блоку из нескольких Тем, показывающая связи между ними. Выдаётся ученику один раз, чтобы был под рукой — можно распечатать и повесить; размер — по объёму материала.
_Avoid_: шпаргалка, раздатка, справка

**Источник** (`source`):
Сборник, пособие или книга, из которой оцифрованы Задания и теория.
_Avoid_: материал

## Качество содержания

**Оцифровка** (`digitization`):
Перевод страницы Источника в текст Заданий и теории с вырезанными рисунками. Единственный этап, которому доступны сами Источники.

**Пометка** (`flag`):
Отметка агента о сомнительном месте в содержании с причиной (например, «индекс неразборчив на фото»).

**Проверено** (`verified`):
Автор подтвердил, что содержание верно. Ставит только автор; всё непроверенное — черновик. В Комплект попадает только проверенное.
_Avoid_: утверждено, одобрено

## Занятия

**Комплект** (`lesson_kit`):
Всё, что готовится к одному занятию по одной основной Теме: план, Блок теории, Задания на занятии, ДЗ, Входная проверка и Решения ко всему. Не привязан к ученику: один Комплект служит всем ученикам, проходящим эту Тему. Свой для каждого Экзамена; если Тема занимает несколько занятий, у неё несколько Комплектов по порядку.
_Avoid_: материалы, пакет

**Занятие** (`lesson`):
Встреча с конкретным учеником в конкретный день, на которой используется Комплект. Всё, что касается ученика, относится к Занятию, а не к Комплекту.
_Avoid_: урок

**Блок теории** (`theory_block`):
Набор Разделов Конспекта, отобранный под конкретное занятие и показываемый на слайдах.
_Avoid_: теория к уроку

**Разобранный пример** (`worked_example`):
Роль Задания в Комплекте: оно стоит перед первым Заданием нового вида и показывается вместе с Решением. Им может стать любое Задание с проверенным Решением.

**ДЗ** (`homework`):
То, что ученик делает сам до следующего занятия: Задания по Теме занятия и, при необходимости, чтение Разделов Конспекта — в том числе другой Темы, например следующей.
_Avoid_: домашка

**Входная проверка** (`entry_check`):
5–7 Заданий на ~10 минут по ДЗ, плюс 1–2 вопроса по теории, если было чтение; входит в Комплект того же занятия, что и ДЗ, а проводится в начале следующего.
_Avoid_: проверочная, летучка
