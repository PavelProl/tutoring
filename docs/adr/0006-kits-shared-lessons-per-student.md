# Комплект общий для всех учеников; ученик — только в Занятии

Комплект не привязан к ученику: один Комплект по Теме, цели и глубине школьной или экзаменационной подготовки служит всем, кому подходит, и хранится в репозитории содержания. Всё, что касается конкретного ученика, относится к Занятию, а при будущем введении учёта будет храниться отдельно вне git. В репозитории содержания нет персональных данных, даже псевдонимов.

Уточнение 16.11.2026: учёт учеников пока не используется; пустая локальная заготовка удалена после проверки. Каталог и формат данных вводятся только при реализации этого расширения. Отсутствие каталога не мешает подготовке общих Комплектов.

## Considered Options

- **Комплект на каждого ученика.** Позволяет подстраивать материалы, но при многих учениках — десятки почти одинаковых Комплектов; дополнительную практику вместо этого даёт Тренировка.
- **Комплекты в репозитории содержания с псевдонимом ученика.** Удобно копировать, но смешивает общий материал с учётом учеников.
