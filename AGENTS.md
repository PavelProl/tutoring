# tutoring

Платформа репетитора по школьной химии: библиотека теории и Заданий по Темам и сборка материалов к занятиям, включая подготовку к ОГЭ/ЕГЭ при необходимости. Объясняй решения с доводами.

- Работай с оцифрованным содержанием. Источники (фото сборников, PDF-книги) лежат вне репозитория, в `chemistry/tutoring-sources/` (путь определяй от корня chemistry); открывай их только при оцифровке. Исключение — образцы оформления в `chemistry/tutoring-sources/references/`: их открывай, когда работаешь над оформлением.
- В этом проекте «задача» и «задание» — всегда про химию (в документах и коде — «Задание»); работа по разработке — «issue» в GitHub Issues. Словарь — в `GLOSSARY.md`.
- Язык. По-русски пишутся также GLOSSARY, ADR, AGENTS и скиллы. Заголовки и описания issues и PR — по-английски. Термины словаря в английских текстах — по их английским именам из `GLOSSARY.md` (`exercise`, `topic`, `lesson_kit`).
- Issues — в `PavelProl/tutoring`, включая Конспекты и чтение источников. Issue, где нужны решения или проверка автора, помечен `hitl`; issue, который агент может сделать сам, — `afk`.
- Агент самостоятельно ведёт коммиты, push и PR в рамках поручения. Проверки, приёмка содержания и подтверждение синхронизации — по `docs/workflow.md`; требования к выдаче — в `docs/lesson-output.md`.
- Методические решения (какая Тема следующая, деление курса на Темы, глубина) утверждает автор. Агент предлагает готовое решение с доводами и 2–3 вопросами с рекомендуемыми ответами; до подтверждения пишет «предложено».
- Темы и глубину определяй по школьному содержанию и цели занятия. Название экзамена на сборнике не ограничивает его использование; используй теорию, краткие справки, Задания и образцовые Решения всех относящихся источников. Экзаменационная привязка — дополнительная характеристика.
- Один чат — один issue. Когда чат разрастается, предложи новый.
- Разбираешь источник или оцифровываешь Задания — сначала прочитай `docs/reading-sources.md`.
- Источники называй так, как названы их файлы и папки (`chemistry_base.pdf`, `chem_oge_2026_30_tests_Doronkin`), без сокращений. Проверка полноты и запросы материалов — в `docs/reading-sources.md`; реестр — в `tutoring-content/source-inventory.md`.
- Когда закрывается веха (Тема, разбор книги, инструмент), предложи запись в `docs/journal.md`.
