# Содержание хранится отдельно от кода

Код проектируем так, будто он станет публичным, а оцифрованное содержание из сборников (Задания, Конспекты) хранится в отдельном приватном git-репозитории; код находит его по настраиваемому пути. Выбрали это, потому что платные материалы, раз попав в историю git публичного репозитория, придётся вычищать из всей истории.

## Considered Options

- **Один приватный репозиторий со всем.** Проще на старте, но перед публикацией кода — чистка истории.
- **Один репозиторий, содержание в `.gitignore`.** Содержание остаётся без истории и резервной копии, а история правок заданий нужна как метрика качества оцифровки.
