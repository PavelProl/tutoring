# Сводка по проекту

Ответь в 5–10 строк, проверив оба репозитория:

1. По course-map.md и текущему issue — готовые Темы, цель школьной/экзаменационной подготовки и согласованный следующий шаг. Приоритет определяется ближайшей потребностью автора, а не названием экзамена на книге.
2. По source-inventory.md — полнота реестра, пробелы обработки и ожидаемые страницы.
3. По GitHub Issues — активный issue, последний комментарий и препятствия; по PR — что требует завершения.
4. По Git — незакоммиченное, неотправленные коммиты, расхождение с main после успешного fetch. При ошибке сети явно сообщи, что удалённое состояние не подтверждено.
5. По материалам — что ожидает проверки автора и что доступно в «Занятия/Готово». Новый механизм выдачи пока не реализован.

Не называй чистую рабочую копию доказательством синхронизации. Учёт учеников отложен. Подробности раскрывай по запросу автора.
