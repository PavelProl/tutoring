# Одно Задание — один Markdown-файл

Каждое Задание хранится отдельным Markdown-файлом: поля (Тема, Ответ, Источники, Проверено…) — в YAML-шапке, условие и Решение — текстом ниже. Файлы — источник истины; база данных, когда понадобится, собирается из них как индекс. Так правка одного Задания видна в истории git отдельно (это метрика качества оцифровки), а файлы читаются глазами и в Obsidian.

Файлы лежат по папкам Источников, ID — первый Источник + страница + номер (`exercises/doronkin-ege-2027/p045-03.md`): на ID ссылаются Комплекты, а Источник у Задания, в отличие от Темы, никогда не меняется. Дубль из другого Источника дописывается в существующий файл. Задание из нескольких групп делится по группам с латинской буквой в ID (`eremin-8/p049-09a`): занятие и ДЗ могут брать разные группы.

## Considered Options

- **Один YAML/JSON-файл на страницу Источника.** Меньше файлов, но правки разных Заданий смешиваются в истории, а дубль из другого Источника некуда положить.
- **Сразу SQLite.** Нет истории правок в git и нельзя прочитать без инструментов; рано для одной Темы.
