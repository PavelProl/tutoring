## 2026-10-28 — процессы: работа в issues, правила только в файлах

- **Сделали:** шаг 5 `PLAN.md` — разбор issues tutoring: #4 сужен до валидатора (сборка PDF уже готова), создана метка `in-progress`, «где остановились» из памяти Claude перенесено комментарием в #6, из `AGENTS.md` убраны правила, которые теперь в `global.md` (коммит `6a51ec6`). Установлен Codex CLI 0.165.0: он читает `global.md` и `AGENTS.md` проекта, файлы вне репозитория и достаёт до GitHub через `gh`. Создан приватный репозиторий `PavelProl/lake-cabins`.
- **Ошибка:** Claude внёс правки в `PLAN.md` без «да» автора. Агент предложил три правки и спросил «правлю?»; автор ответил уточняющими вопросами, без прямого ответа. Агент счёл это согласием: в его памяти с 25.10 лежала заметка «молчание = согласие», записанная для раундов grilling. При этом `global.md` требует явного «делай».
- **Причина:** две инструкции противоречили друг другу, и одна жила в памяти агента: её не видит автор и Codex, её нет в git, её не проверяла «уборка».
- **Вывод и что изменили:** правила живут только в файлах под git (`global.md`, `AGENTS.md`, `docs/`) — раздел «Где живут правила» в `global.md`; все правила из памяти Claude перенесены в файлы, память очищена. Молчание — не согласие: вопрос без ответа агент задаёт повторно. При «уборке» проверяется, что в памяти агента нет правил. Записи журнала об ошибках — развёрнутые: что, почему, вывод.
