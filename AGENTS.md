# tutoring

Платформа репетитора по химии (ОГЭ/ЕГЭ): библиотека теории и заданий по темам и сборка из неё материалов к занятиям. Объясняй решения с доводами.

- Работай с оцифрованным содержанием. Источники (фото сборников, PDF-книги) лежат вне репозитория, в `../tutoring-sources/`; открывай их только при оцифровке. Исключение — образцы оформления в `../tutoring-sources/references/`: их открывай, когда работаешь над оформлением.
- В этом проекте «задача» и «задание» — всегда про химию (в документах и коде — «Задание»); работа по разработке — «issue» в GitHub Issues. Словарь — в `GLOSSARY.md`.
- Язык. По-русски пишутся также GLOSSARY, ADR, AGENTS и скиллы. Термины словаря в английских текстах — по их английским именам из `GLOSSARY.md` (`exercise`, `topic`, `lesson_kit`).
- Issues — в `PavelProl/tutoring`, включая Конспекты и чтение источников. Issue, где нужны решения или проверка автора, помечен `hitl`; issue, который агент может сделать сам, — `afk`.
- Методические решения (какая Тема следующая, деление курса на Темы, глубина) утверждает автор. Агент предлагает готовое решение с доводами и 2–3 вопросами с рекомендуемыми ответами; до подтверждения пишет «предложено».
- Один чат — один issue. Когда чат разрастается, предложи новый.
- Материалы для ученика: крупный шрифт, не мельчить; решения в формате «задание → решение → ответ», без пометок для преподавателя. Занятия идут онлайн, в Miro.
- Разбираешь источник или оцифровываешь Задания — сначала прочитай `docs/reading-sources.md`.
- Источники называй так, как названы их файлы и папки (`chemistry_base.pdf`, `chem_oge_2026_30_tests_Doronkin`), без сокращений. Порядок источников и просьбы докинуть фото — в `docs/reading-sources.md`.
- Собираешь Конспект — сначала прочитай `docs/building-notes.md`.
- Когда закрывается веха (Тема, разбор книги, инструмент), предложи запись в `docs/journal.md`.
